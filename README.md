# Syed Zain Ull Abidin — Portfolio

This is the source code for my personal portfolio, built with Next.js and Tailwind CSS. It showcases my experience as an AI/ML Engineer, Data Scientist, and Data Analyst.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS (Custom CSS Variables & Classes)
- **Animations:** Framer Motion
- **Language:** TypeScript

## Features
- **Responsive Design:** Optimized for all screen sizes.
- **Dark Mode Aesthetic:** Custom glassmorphism and subtle gradients without feeling overwhelmingly "AI-generated".
- **Dynamic Routing:** Smooth scrolling navigation with Intersection Observer logic.

## Running Locally

To run this project locally, simply clone the repository and run:

```bash
npm install
npm run dev
```

Then, open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment
This project is configured for seamless deployment on Vercel. There are no environment variables required for the base portfolio.
